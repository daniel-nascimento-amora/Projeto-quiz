# Projeto Quiz  desenvolvedor Daniel Amora

//Projeto em TypeScript/CSS

Mini Quiz para Testar o Conhecimento Geral

Tela da Home para Iniciar o Quiz
E uma segunda Tela, do Quiz propriamente dito.

O usuário deve colocar seu nome e clicar em "JOGAR".

A tela do Quiz é iniciada.

Ao escolher a opção correta, será retorno um emoji 
de "acertou", e escolhendo a opção errada, retorna um emoji de "errou". 

A cada pergunta respondida, a pergunta seguinte será carregada automaticamente após 2 segundos (não é necesário quanlquer ação do usuário como "avançar para próxima pergunta".)

Após responder todas as pergunta do Quiz, a tela final é:
"Fim do Jogo!"
"Parabéns por concluiu o quiz!"
